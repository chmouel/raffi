Raffi needs nothing else to run. Pick whichever install method suits your
system.

## Package managers

<Tabs>
  <TabItem label="Arch Linux">
    The AUR has a prebuilt package:

    ```bash
    yay -S raffi-bin
    ```

    `paru -S raffi-bin` works too. The `raffi` package builds from source
    instead.
  </TabItem>

  <TabItem label="Nix">
    From the unstable channel:

    ```bash
    nix-shell -p raffi
    ```

    Or add it to your NixOS configuration:

    ```nix
    environment.systemPackages = with pkgs; [
      raffi
    ];
    ```
  </TabItem>

  <TabItem label="Homebrew">
    Homebrew and Linuxbrew both work:

    ```bash
    brew tap chmouel/raffi https://github.com/chmouel/raffi
    brew install raffi
    ```
  </TabItem>

  <TabItem label="Cargo">
    If you have a [Rust toolchain](https://rustup.rs/):

    ```bash
    cargo install raffi
    ```
  </TabItem>
</Tabs>

## Release archives

The [releases page](https://github.com/chmouel/raffi/releases) has archives
and packages for each version. Extract the archive and put `raffi` somewhere
in your `PATH`:

```bash
tar xzf raffi-*.tar.gz
sudo install -m 755 raffi /usr/local/bin/
```

If you only use Raffi through Fuzzel, see the [Fuzzel page](../integration/fuzzel/#fuzzel-only-builds)
for a smaller build.

## Building from source

```bash
git clone https://github.com/chmouel/raffi.git
cd raffi
cargo install --path .
```

`cargo build --release` works too if you'd rather copy
`target/release/raffi` yourself.

## Check that it works

```bash
raffi --help
```

prints every option. Run `raffi` on its own and you should see the
applications installed on your system, ready to search.

<Aside type="tip">
Next, follow the [quick start](../quickstart/) to write your first launchers
and bind Raffi to a key.
</Aside>

## Working on Raffi

To hack on Raffi, clone the repository and install the git hooks. They check
formatting, lints and tests before you push:

```bash
pip install pre-commit
pre-commit install
cargo test
```
