title: CLI Options
description: Command-line flags and options for Raffi
---

Raffi supports several command-line flags to control its behavior. All flags are optional and override settings from the configuration file.

## Global Flags

**`--help`** `boolean` (default: `false`)

Print help message and exit.


**`--version`** `boolean` (default: `false`)

Print version information and exit.


## Configuration

**`-c, --configfile`** `string` (default: `~/.config/raffi/raffi.yaml`)

Path to the YAML configuration file. Launcher entries are read from `launchers.yaml` in the same directory when this file has no `launchers:` section.

  Supports tilde expansion (`~/`) and environment variable expansion (`${VAR}`).

  ```bash
  raffi -c ~/custom/config.yaml
  raffi --configfile ~/custom/config.yaml
  ```


**`-o, --option`** `KEY=VALUE` (repeatable)

Override any YAML configuration setting from the command line.

  Keys use dot-separated paths matching `raffi.yaml` (such as `general.theme=nord`, `addons.emoji.close_on_action=false`, or `launchers.firefox.close_on_action=false`). Sequence entries under `addons.script_filters`, `addons.web_searches`, and `addons.text_snippets` can be addressed by numeric index, `name`, or `keyword`. Values are parsed as YAML booleans, numbers, lists, or strings, and validated against the configuration schema.

  ```bash
  raffi -o general.close_on_action=false
  raffi -o addons.emoji.close_on_action=false -o general.theme=nord
  raffi -o 'addons.script_filters.Timezones.close_on_action=false'
  ```


**`--keep-open`** `boolean` (default: `false`)

Keep the Raffi window open after executing an action (shorthand for `-o general.close_on_action=false`). Individual addons or launchers can still override this via `-o addons.<name>.close_on_action=true`.

  ```bash
  raffi --keep-open
  ```


**`--check-config`** `boolean` (default: `false`)

Validate the configuration file and `launchers.yaml` next to it against the JSON Schema and exit without launching anything.

  Every problem is printed with the file name, line number and path of the offending key, for example `launchers.yaml:12: /firefox: Additional properties are not allowed ('binnary' was unexpected)`. The exit code is non-zero when problems are found. Old v0 (flat) configs are checked as if migrated, but the file is left untouched and line numbers refer to the original file.

  Requires the `config-validation` Cargo feature, which is enabled by default. Builds made with `--no-default-features` report that validation is unavailable.

  ```bash
  raffi --check-config
  raffi --check-config -c ~/custom/config.yaml
  ```


**`--generate-schemas`** `boolean` (default: `false`)

Write or refresh both JSON Schema files next to the selected config file and
exit. Use `--configfile` to choose the config directory.

  ```bash
  raffi --generate-schemas --configfile /path/to/raffi.yaml
  ```


**`--install-browser-host`** `boolean` (default: `false`)

Register Raffi as the native messaging host of the Vicinae browser extension, for the [browser tabs](../../features/browser-tabs/) list, and exit.

  Writes a `com.vicinae.vicinae.json` manifest pointing to the running `raffi` binary for every Chromium or Firefox based browser with a configuration directory, and prints each file. A manifest Raffi did not install, such as one that starts Vicinae, is left alone unless `--force` is given.

  ```bash
  raffi --install-browser-host
  raffi --install-browser-host --force
  ```


**`--uninstall-browser-host`** `boolean` (default: `false`)

Remove the browser host manifests that start Raffi and exit. Manifests of other programs are kept.

  ```bash
  raffi --uninstall-browser-host
  ```


**`--force`** `boolean` (default: `false`)

With `--install-browser-host`, replace manifests Raffi did not install, such as the ones that start Vicinae.


## UI Options

**`-u, --ui-type`** `string`

By default Raffi opens its own window. Pass `fuzzel` to show your entries in
[Fuzzel](../../integration/fuzzel/) instead, a legacy option with fewer features.

  ```bash
  raffi -u fuzzel
  ```

**`--app-name`** `string` (default: `com.chmouel.raffi`)

Set the application ID reported for Raffi's window on Linux. This is useful for targeting the window with compositor or window-manager rules.

  ```bash
  raffi --app-name org.example.raffi
  ```


**`-I, --no-icons`** `boolean` (default: `false`)

Disable icon loading for faster startup.

  When enabled, no icons will be displayed in the launcher interface. This can significantly speed up startup time, especially on first launch.

  ```bash
  raffi -I
  ```


**`-i, --initial-query`** `string`

Pre-fill the search field with an initial query.

  Useful for launching Raffi with a specific search term already entered.

  Addon keywords need their trailing space here too, so use `-i "sn "` to open a
  snippet source directly.

  Opening help temporarily clears the initial query so all help
  entries are visible. Closing help restores it.

  ```bash
  raffi -i firefox
  ```

**`-1, --select-1`** `boolean` (default: `false`)

With a non-empty `--initial-query`, automatically activate the only selectable
result after its results finish loading. The option applies only to the
initial query; typing or refining the query later does not trigger automatic
activation.

  ```bash
  raffi -1 -i firefox
  raffi --select-1 --initial-query firefox
  ```

**`-t, --theme`** `string` (default: `dark`)

Select the color theme.

  Valid values:

- `dark` - Sleek Obsidian dark theme (default)
- `light` - Rose Pine Dawn light theme
- `catppuccin` / `catppuccin-mocha` - Catppuccin Mocha dark theme
- `catppuccin-latte` - Catppuccin Latte light theme
- `tokyo-night` / `tokyonight` - Tokyo Night dark theme
- `nord` - Nord dark theme
- `gruvbox` - Gruvbox dark theme
- `dracula` - Dracula dark theme
- `rose-pine` / `rosepine` - Rosé Pine dark theme
- `kanagawa` - Kanagawa Wave dark theme

  ```bash
  raffi -t tokyo-night
  ```

**`--opacity`** `number` (default: `0.95`)

Opacity of the window backgrounds, from `0.0` (see-through) to `1.0` (solid). Text and icons stay opaque. Overrides `general.opacity`. Below `1`, the default `renderer: auto` draws on the GPU, which transparency needs. See [Transparency and Blur](../../features/themes/#transparency-and-blur).

  ```bash
  raffi --opacity 0.7
  ```

## Execution Options

**`-p, --print-only`** `boolean` (default: `false`)

Print the command to stdout instead of executing it.

  Useful for debugging or integrating with window managers that execute commands separately.

  ```bash
  raffi -p
  # Output: env -- firefox --marionette
  ```

  The output is a **shell-ready command line**: arguments that need it are single-quoted, so the
  result is meant to be evaluated by a shell (`sh -c "$cmd"`) rather than word-split. Script entries
  print as `<interpreter> -c '<script>' [<interpreter> <args>...]`, which means a multi-line script
  produces multi-line output.

  Commands given by name are printed with an `env` prefix. That makes the receiving shell run the
  program from your `PATH`, the same one Raffi would launch itself, instead of a shell builtin,
  alias or function that happens to share the name. Entries configured with a full path are printed
  as-is.

  Example with Sway:

  ```bash
  cmd=$(raffi -p) && [ -n "$cmd" ] && swaymsg exec -- "$cmd"
  ```

  Do not pipe the output through `xargs`: `xargs` strips quotes and splits on whitespace, which
  mangles arguments containing spaces and breaks `script` entries. Always quote `"$cmd"`.


**`-P, --default-script-shell`** `string` (default: `bash`)

Set the default shell interpreter for script entries.

  Used when a configuration entry has a `script` field but no explicit `binary` field. Common values include `bash`, `zsh`, `sh`, `python3`, etc.

  ```bash
  raffi --default-script-shell zsh
  ```


## Cache Management

**`-r, --refresh-cache`** `boolean` (default: `false`)

Refresh the cached icon paths.

  Raffi caches icon locations from system directories to speed up subsequent launches. Use this flag to force regeneration of the cache, for example after installing new icon themes.

  ```bash
  raffi -r
  ```

  Cache location: `$XDG_CACHE_HOME/raffi/icon.cache` (defaults to `~/.cache/raffi/icon.cache`)


## Examples

### Basic Usage

Launch with default settings:

```bash
raffi
```

### Custom Configuration

Use a custom config file:

```bash
raffi --configfile ~/.config/work/raffi.yaml
```

### Light Theme

Launch with the light theme and no icons:

```bash
raffi -t light -I
```

### Print-Only Mode

Print the selected command without executing:

```bash
raffi -p
```

### Pre-filled Search

Launch with an initial search query:

```bash
raffi -i "screenshot"
```

### Refresh Icons and Use Custom Shell

Refresh icon cache and use zsh for scripts:

```bash
raffi -r --default-script-shell zsh
```

## Precedence

Command-line flags always take precedence over settings in the configuration file's `general` section. This allows you to override persistent defaults on a per-launch basis.
