Raffi is a keyboard-driven search box for your Wayland desktop. From one
place you can open apps, browse files, switch windows, paste from your
clipboard history, fill in passwords, do sums and convert currencies. It is
written in Rust, opens fast, and runs without a daemon or database.

<Image src={mainScreenshot} alt="Raffi with the preview pane open" width={800} />

## What you can do with it

Raffi works as soon as it is installed. With no config, typing searches
your installed applications, open windows and system commands in one list,
along with browser tabs, media players and audio devices when the tools for
them are set up.

Some addons answer as soon as your query looks right:

```
2 + 2 * 5
$10 to eur
10 km to mi
time tokyo
```

Others start with a keyword and give you a list to pick from: `/` or `~/`
for the file browser, `clip ` for clipboard history, `win ` for open windows,
`pass ` for passwords, and many more. You can add your own web searches, text
snippets and script filters, each under a keyword you choose. Script filters
use the Alfred JSON format, so any command that prints a list can feed Raffi.

You can also add entries of your own: a command with arguments, an inline
script in Bash, Python or any other interpreter, or an entry that only shows
up when a program is installed.

Press `Ctrl+/` or type `?` to see every keyword and shortcut your config
turns on. When a list has more than one view, `Ctrl+Tab` switches between
them.

## Making it yours

Settings live in `~/.config/raffi/raffi.yaml`. This one picks a theme,
chooses what the main list shows as you type, keeps installed apps listed,
and adds a Google search under `g`:

```yaml title="raffi.yaml"
general:
  theme: dark
  main_view: [launchers, windows, browser_tabs, system, clipboard]
addons:
  apps:
    enabled: true
  web_searches:
    - name: Google
      keyword: g
      url: "https://google.com/search?q={query}"
```

Your own entries go in `~/.config/raffi/launchers.yaml`:

```yaml title="launchers.yaml"
firefox_private:
  binary: firefox
  args: [--private-window]
  icon: firefox
  description: Firefox private window
```
