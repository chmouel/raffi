Raffi is a fast, keyboard-driven launcher for Wayland written in Rust,
inspired by Alfred and Raycast on macOS. Bind it to a shortcut and start
typing: with no setup at all, one search box finds your apps, open windows,
browser tabs, bookmarks, passwords, files, snippets, and clipboard history,
ranking recent picks first and offering fallback actions like web search
when nothing matches. You do not need a background daemon to use it. Running
the optional [`raffi --server`](reference/cli-options/#cache-management)
keeps the window about a third faster to open, warms caches in the
background, and records your clipboard history.

## What comes out of the box

Built-in tools handle everyday desktop tasks without configuration. Math,
currency and unit conversions, colors, and world clocks answer directly as
you type:

```
2 + 2 * 5
$10 to eur
10 km to mi
time tokyo
```

You can browse files with inline previews for code, images, videos, and
PDFs; switch windows on Sway, Hyprland, or niri; control audio, media,
Bluetooth, and power actions; pull logins from
[pass](features/password-store/) or [Bitwarden](features/bitwarden/); and
search [Slack](features/slack/).

The [clipboard history](features/clipboard-history/) searches text inside
screenshots with OCR, expires one-time codes, ignores password managers, and
saves any entry as a [text snippet](features/text-snippets/) that pastes
straight into your active window with dynamic placeholders like today's
date.

Press `Ctrl+/` or type `?` to see every active keyword and shortcut. When a
list has multiple views, `Ctrl+Tab` switches between them.

## Making it yours

Everything lives in plain YAML with editor autocomplete through checked-in
[JSON Schemas](reference/yaml-schema/). You can add custom commands, inline
scripts, conditional entries that adapt to whichever machine you are on, web
searches, and [Alfred-compatible script filters](features/script-filters/)
with rich previews and action menus. Bind extra shortcuts like
`raffi -i "clip "` to jump straight into any mode, pick from built-in
[themes](features/themes/), or use [Fuzzel](integration/fuzzel/) as the
frontend.

Settings live in `~/.config/raffi/raffi.yaml`:

```yaml title="raffi.yaml"
general:
  theme: dark
  main_view: [launchers, windows, browser_tabs, system, clipboard]
addons:
  apps:
    enabled: true
  web_searches:
    - name: Google
      keyword: g
      url: "https://google.com/search?q={query}"
```

Your own entries go in `~/.config/raffi/launchers.yaml`:

```yaml title="launchers.yaml"
firefox_private:
  binary: firefox
  args: [--private-window]
  icon: firefox
  description: Firefox private window
```
