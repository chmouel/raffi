Raffi is an application launcher for Wayland. You write down the programs,
scripts and commands you use in a YAML file, and Raffi puts them one fuzzy
search away. It is written in Rust, opens fast, and runs without a daemon or
database.

<Image src={mainScreenshot} alt="Raffi with the preview pane open" width={800} />

## What you can do with it

Your launchers can carry arguments, icons and descriptions. They can run an
inline script in Bash, Python or any other interpreter, and they can hide
themselves unless a condition holds, such as a program being installed or an
environment variable being set. With no config at all, Raffi lists the
applications installed on your system.

The same search box also reaches a set of addons. Some answer as soon as your
query looks right:

```
2 + 2 * 5
$10 to eur
10 km to mi
time tokyo
```

Others start with a keyword and give you a list to pick from: `/` or `~/`
for the file browser, `clip ` for clipboard history, `win ` for open windows,
`pass ` for passwords, and many more. You can add your own web searches, text
snippets and script filters, each under a keyword you choose. Script filters
use the Alfred JSON format, so any command that prints a list can feed Raffi.

Press `Ctrl+/` or type `?` to see every keyword and shortcut your config
turns on. When a list has more than one view, `Ctrl+Tab` switches between
them.

## A few examples

A launcher with arguments:

```yaml
firefox:
  binary: firefox
  args: [--marionette]
  icon: firefox
  description: Firefox with marionette enabled
```

An inline Python script:

```yaml
hello_python:
  binary: python3
  script: |
    import os
    print("Hello from Python!")
    print(os.environ)
  description: Hello Python script
  icon: script
```

An entry that only shows up in GNOME:

```yaml
gnome_app:
  binary: gnome-tweaks
  description: GNOME Tweaks
  ifenveq: [DESKTOP_SESSION, GNOME]
```
