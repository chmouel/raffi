Web searches open a search page in your browser from Raffi. Each one pairs a
keyword with a URL template: type the keyword, a space and your query, press
Enter, and Raffi opens the URL with your query filled in.

<Image src={webSearchScreenshot} alt="GitHub web search with a resolved URL in the preview pane" width={800} />

## Quick start

```yaml raffi.yaml
addons:
  web_searches:
    - name: "Google"
      keyword: "g"
      url: "https://google.com/search?q={query}"
      icon: "google"
```

Type `g rust traits`. Raffi shows a row reading "Search Google for 'rust
traits'" and the resolved URL in the preview pane. Press Enter to open
`https://google.com/search?q=rust%20traits`.

While you are still typing the keyword, a row naming the search appears;
Enter or Tab on it jumps into the search. Esc closes Raffi.

### URL encoding

The query replaces every `{query}` in the template and is percent-encoded
first. Spaces become `%20`, other special characters are encoded (`&` becomes
`%26`), and the unreserved characters A to Z, a to z, 0 to 9, `-`, `.`, `_`
and `~` stay as they are.

## Custom Search Engines

Any site that puts the search terms in its URL works. Search the site for
`test`, copy the address from the browser, and replace `test` with `{query}`:

```text
https://example.com/search?q=test
https://example.com/search?q={query}
```

The parameter does not have to be `q`, and `{query}` can sit anywhere in the
URL, as in `https://example.com/find?search={query}`. Then add it to your
config:

```yaml raffi.yaml
addons:
  web_searches:
    - name: "Example"
      keyword: "ex"
      url: "https://example.com/search?q={query}"
```

## Configuration

Web searches are a list under `addons.web_searches` (default: `[]`).

**`name`** `string` (required)

Name shown in the search row, as in "Search Google for 'rust traits'".

**`keyword`** `string` (required)

Text that starts the search. Type it followed by a space: `g ` enters the
search, while `g` alone keeps searching the main list. Script filters, text
snippet sources and the emoji and clipboard triggers are checked first, so
they win over a web search with the same keyword.

**`url`** `string` (required)

URL template. Every `{query}` is replaced with the percent-encoded query, as
described in [URL encoding](#url-encoding). A leading `~/` and `${VAR}`
references are expanded when the config loads, which lets you keep part of a
URL, such as an internal host name, in an environment variable.

**`icon`** `string`

Icon name from your icon cache, shown next to the search row.

**`close_on_action`** `boolean` (default: `true`)

Close Raffi after opening the URL. When unset, `general.close_on_action`
applies.

```yaml raffi.yaml
addons:
  web_searches:
    - name: "Google"
      keyword: "g"
      url: "https://google.com/search?q={query}"
      icon: "google"
    - name: "GitHub"
      keyword: "gh"
      url: "https://github.com/search?q={query}&type=repositories"
      icon: "github"
    - name: "Wikipedia"
      keyword: "wiki"
      url: "https://en.wikipedia.org/wiki/Special:Search?search={query}"
      icon: "wikipedia"
      close_on_action: false
```

## Requirements

Raffi opens URLs with `xdg-open`, which uses your default browser.
