The native interface includes a built-in file browser for quick filesystem navigation using keyboard shortcuts.

<Aside type="note">
The file browser is only available in **native mode**. It is not available when using Fuzzel mode.
</Aside>

## Overview

Navigate your filesystem directly from the launcher with fuzzy filtering, hidden file support, keyboard-driven actions, drag-and-drop to other applications, and a right-hand preview pane. Image previews scale to the largest size that fits the preview pane while keeping their aspect ratio and rescale when the window is resized; file details appear below the image and can be reached by scrolling the pane with Ctrl+J / Ctrl+K.

<Image src={fileBrowserScreenshot} alt="File browser example" width={800} />

## Activation

Start the file browser by typing one of these prefixes:

- Type `/` to browse from the root filesystem
- Type `~` to browse from your home directory

### Examples

```text
/                  # Browse root directory
~                  # Browse home directory
/home/user/        # Browse specific directory
~/Documents/       # Browse Documents folder
```

## Navigation

### Directory Structure

- **Directories** are listed first in accent color
- **Files** are listed after directories
- Current path shows in the input field

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Enter** | Navigate into directory OR run `action` on a file (`xdg-open` by default) |
| **Ctrl+Enter** | Run `secondary_action` on a file or directory (copy path by default) |
| **Tab** | Autocomplete selected entry into search bar |
| **Backspace** | On a trailing `/`, go up to the parent directory |
| **Ctrl+H** | Toggle hidden file visibility |
| **Ctrl+O** | Open the current directory in a file manager |
| **Ctrl+S** | Cycle the sort order: name, modified date, created date |
| **Ctrl+.** | Cycle the listing: all entries, files only, directories only |
| **Ctrl+J** / **Ctrl+K** | Scroll the right-hand preview pane down / up |
| **Ctrl+P** | Toggle right-hand file/directory/image preview pane |
| **Esc** | Exit file browser |
| **↑/↓** | Navigate through results |

## Fuzzy Filtering

Text after the last `/` fuzzy-filters the current directory listing:

<Tabs>
<TabItem label="Basic Filter">
```text
/home/us
# Filters /home/ by "us"
# Matches: user, username, usr, etc.
```
</TabItem>
<TabItem label="Deep Filter">
```text
~/Documents/proj
# Filters ~/Documents/ by "proj"
# Matches: projects, my-project, old_projects, etc.
```
</TabItem>
<TabItem label="Extension Filter">
```text
~/Downloads/.pdf
# Filters ~/Downloads/ by ".pdf"
# Shows all PDF files
```
</TabItem>
</Tabs>

## Actions

### Open File

1. Navigate to file
2. Press **Enter**
3. File opens with `xdg-open` (system default application)

```text Example
~/Documents/report.pdf
[Enter] → Opens PDF in default viewer
```

### Navigate Directory

1. Navigate to directory
2. Press **Enter**
3. Directory contents are displayed

```text Example
~/Documents/
[Enter] → Shows contents of Documents/
```

### Go Up a Directory

With the input ending in `/`, press **Backspace** to jump to the parent directory. The directory you came from stays selected, so **Enter** takes you straight back.

```text Example
~/Projects/myapp/src/
[Backspace] → Input becomes: ~/Projects/myapp/  (src/ selected)
```

### Copy Path

1. Navigate to file or directory
2. Press **Ctrl+Enter** (or Ctrl+click the row)
3. Full path copied to clipboard

```text Example
~/Documents/report.pdf
[Ctrl+Enter] → Copies: /home/user/Documents/report.pdf
```

This is the default `secondary_action`; see [Configuration](#configuration) to change it.

### Drag and Drop

Files and directories can be dragged **out of raffi** into any application that accepts drops (file managers, editors, terminals, browsers, email clients...):

1. Press and hold the left mouse button on a file browser row
2. Move the pointer — the drag starts once the pointer moves a few pixels (~8 logical px, typically while still inside the row)
3. Release over the target application to drop

```text Example
~/Documents/report.pdf
[press, move to a file manager] → Drops the file there
```

A quick press and release on a row still activates it like **Enter** would.

The drag offers the file as `text/uri-list` (what file managers expect) and as plain UTF-8 text of the full path (what terminals and most editors take), so text targets that are not drop-aware may still receive the path if they accept text drops.

<Aside type="note">
Dragging out of raffi requires the native Wayland interface (the default). It does not work under XWayland, X11, or in Fuzzel mode.
</Aside>

<Aside type="note">
raffi is a drag source only: it does not accept files dropped **into** it.
</Aside>

### Open in File Manager

Press **Ctrl+O** to open the directory you are browsing in a graphical file manager. With Nautilus, Dolphin, Nemo and Caja the entry selected in raffi is also selected in the file manager; other file managers just open the directory. Raffi picks your desktop's own file manager when it is installed (Dolphin on KDE, Nautilus on GNOME, Thunar on XFCE, Nemo on Cinnamon, Caja on MATE, PCManFM on LXQt/LXDE, and so on). On other sessions such as Hyprland or Sway it uses the first one it finds, and falls back to `xdg-open`. Set [`file_manager`](#configuration) to choose one yourself.

```text Example
~/Projects/myapp/src/
Selected: main.rs
[Ctrl+O] → Opens ~/Projects/myapp/src/ in your file manager with main.rs selected
```

### Autocomplete

1. Navigate to file or directory
2. Press **Tab**
3. Entry is autocompleted into search bar

```text Example
Current: /home/us
Selected: user/
[Tab] → Input becomes: /home/user/
```

## Configuration

Configure the file browser in `raffi.yaml`:

```yaml raffi.yaml
addons:
  file_browser:
    enabled: true
    show_hidden: false
    sort: name
    sort_reverse: false
    show: all
    backspace_updir: true
    action: open
    secondary_action: copy
    file_manager: thunar
```

### Configuration Options

**`enabled`** `boolean` (default: `true`)

Enable or disable the file browser addon


**`show_hidden`** `boolean` (default: `false`)

Show hidden files (dotfiles) by default. Can be toggled at runtime with Ctrl+H.


**`sort`** `string` (default: `name`)

Initial order of the listing. Directories always come before files. Press Ctrl+S to cycle through the modes while browsing; the hint bar shows the current one.

- `name`: alphabetical, ignoring case
- `modified` (or `date`): last modification time, newest first
- `created`: creation time, newest first. Entries on filesystems that do not record it go last.


**`sort_reverse`** `boolean` (default: `false`)

Reverse the order of whichever `sort` mode is active: Z to A for `name`, oldest first for `modified` and `created`. Directories still come first. Ctrl+S does not change this setting.


**`show`** `string` (default: `all`)

Which entries the listing starts with. Press Ctrl+. to cycle through the modes while browsing; the hint bar shows the current one, and Raffi keeps it until it closes.

- `all`: directories and files
- `files`: files only
- `directories` (or `dirs`): directories only

When directories are hidden you can still type a path such as `~/src/` to enter one, and Tab completes the best hidden match when no visible row matches what you typed. Symlinks count as files, so `directories` hides a link to a directory.


**`backspace_updir`** `boolean` (default: `true`)

When the input ends with `/`, Backspace jumps to the parent directory instead of deleting the slash, like Emacs fido/ido mode. The directory you just left is selected in the parent listing. On `~/` it goes up to the parent of your home directory, and on `/` it is a plain delete. Set to `false` to make Backspace always delete one character.


**`action`** `string` (default: `open`)

What Enter (or a click) does on a file. Enter on a directory always navigates into it. Accepted values:

- `open`: open the file with `xdg-open`
- `copy`: copy the full path to the clipboard
- `insert`: type the full path into the focused app (needs `wtype` or `ydotool`)
- any other string: run it as a shell command, with `{value}` replaced by the full path (also exported as `$RAFFI_VALUE`)


**`secondary_action`** `string` (default: `copy`)

What Ctrl+Enter (or Ctrl+click) does on a file or directory. Takes the same values as `action`.

```yaml raffi.yaml
addons:
  file_browser:
    action: "code {value}"
    secondary_action: insert
```

**`file_manager`** `string` (default: autodetected)

Command used by **Ctrl+O** to open the current directory. The directory is appended as the last argument, or replaces `{value}` if present (it is also exported as `$RAFFI_VALUE`). When the value is just `nautilus`, `dolphin`, `nemo` or `caja` (or a path to one), raffi passes `--select` with the selected entry instead. When unset, raffi detects a file manager as described in [Open in File Manager](#open-in-file-manager).

```yaml raffi.yaml
addons:
  file_browser:
    file_manager: dolphin
    # or a terminal file manager:
    # file_manager: kitty yazi
```


### Disable File Browser

```yaml raffi.yaml
addons:
  file_browser:
    enabled: false
```

## Requirements

<Aside type="caution">
The file browser requires `xdg-open` to open files (standard on most Linux distributions)
</Aside>

<Aside type="note">
Clipboard operations require `wl-copy` (wl-clipboard) for Wayland
</Aside>

## Examples

### Navigate to Documents

<Steps>
1. **Type Prefix**

   Type `~` to start browsing home directory

2. **Filter**

   Type `Doc` to filter for Documents

3. **Navigate**

   Press **Enter** on Documents folder

4. **Browse Files**

   See all files in ~/Documents/

</Steps>

### Open Configuration File

<Steps>
1. **Go to Config**

   Type `~/.config/`

2. **Show Hidden**

   Press **Ctrl+H** if needed

3. **Filter**

   Type filename to filter (e.g., `raf` for raffi)

4. **Open**

   Press **Enter** to open with default editor

</Steps>

### Copy Script Path

<Steps>
1. **Navigate**

   Type `~/bin/` or `/usr/local/bin/`

2. **Find Script**

   Filter by name (e.g., `my-script`)

3. **Copy Path**

   Press **Ctrl+Enter** to copy full path

4. **Use Path**

   Paste into terminal, config, or documentation

</Steps>

## Tips

<Aside type="tip">
Directories are always listed first and highlighted in the accent color, making it easy to distinguish them from files.
</Aside>

<Aside type="tip">
Use fuzzy filtering after the last `/` to quickly find files: `/home/user/doc` matches `/home/user/Documents/`
</Aside>

<Aside type="tip">
Toggle hidden files with **Ctrl+H** without leaving the file browser.
</Aside>

<Aside type="tip">
Drag files straight out of raffi into another application instead of copying their path first.
</Aside>
