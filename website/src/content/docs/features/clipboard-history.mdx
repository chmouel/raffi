Search your clipboard history, preview entries, and copy or paste them again.
Raffi can record the history itself or use [CopyQ](https://hluk.github.io/CopyQ/).

<Image src={clipboardScreenshot} alt="Clipboard history with a release checklist preview and expiry countdowns" width={800} />

## Setup

Start `raffi --server` to let Raffi record your clipboard. Alternatively,
install and run CopyQ. Raffi enables the clipboard browser when its backend is
running at startup.

Type `clip `, including the space, to open the history. To open it from a key
binding:

```sh
raffi -i "clip "
```

To enable the browser even when the backend is not yet running:

```yaml
addons:
  clipboard:
    enabled: true
```

## Choosing a backend

`backend: auto` uses Raffi's history when its server is recording, and CopyQ
otherwise. The server records under `auto` unless CopyQ is already running when
it starts. If CopyQ starts later, Raffi continues recording until the server
restarts.

Set `backend: raffi` or `backend: copyq` to choose one explicitly. Restart the
server after changing this setting. If the history is unavailable, start the
backend and press **Ctrl+R**.

## Browsing and searching

An empty query lists recent entries first. Type words after `clip ` to search
text and file names; every word must match, regardless of case. Exact phrase
matches appear first. Search covers the whole entry, including text that does
not fit in the row.

Text entries shorter than three characters are hidden by default. Set
`min_chars: 0` to show them. Images and files are always shown. Press **Ctrl+R**
to refresh the list.

## Images and URLs

Press **Ctrl+Tab** to cycle between all entries, images and URLs.
**Ctrl+Shift+Tab** cycles backwards. The view stays selected while you search
and resets when you reopen the browser.

### Search text in images

With the Raffi backend, [Tesseract](https://github.com/tesseract-ocr/tesseract)
can make text in screenshots and other images searchable. Install Tesseract and
its language data, enable OCR, and restart `raffi --server`:

```yaml
addons:
  clipboard:
    backend: raffi
    ocr:
      enabled: true
      languages: [eng] # use [eng, fra] if both languages are installed
```

New images are indexed in the background. Search for their text in the browser
or with `raffi clipboard list`. Press **Ctrl+J** in an image preview to scroll
to the recognized text, or press Right at the end of the search field and choose
**Show recognized text** to replace the image with its text. **Escape** brings
the image back. **Copy recognized text** in the same menu puts the full text on
the clipboard.

<Image src={clipboardOcrScreenshot} alt="Searching an image by its recognized text" width={800} />

OCR is off by default and works with the Raffi backend. The server must be
running to process the queue. Temporary entries and password-manager copies
are skipped. OCR text is kept with the image and removed when the image is
deleted. Exclusion and temporary patterns do not inspect text inside images.
Images over 40 megapixels cannot be indexed. Copy an older image again from
its original application to index it.

## Previews

Press **Ctrl+P** to toggle the preview. It shows text, images, file lists and
available formats. Image previews include recognized text when OCR is enabled.
Large previews may be shortened; images over 32 MiB or 40 megapixels can still
be copied but cannot be previewed. Rich text is shown as plain text.

## Actions

| Key | Action |
| --- | --- |
| Enter | Copy the entry |
| Ctrl+Enter | Copy and paste into the previous window on Hyprland |
| Ctrl+D | Delete the entry from the history |

Change Enter and Ctrl+Enter with `action` and `secondary_action`. Both accept
`copy` or `hypr_paste`; `hypr_paste` requires Hyprland. Copying preserves the
entry's formats, including images, file lists and HTML.

To save a text entry as a snippet, press Right at the end of the search field
and choose **Save to snippets**. See [Text Snippets](../text-snippets/#saving-from-the-clipboard).

## Command line

Use `raffi clipboard` to browse and manage the same history without opening the
window:

```sh
raffi clipboard list git          # search the history
raffi clipboard list -k image     # list images
raffi clipboard show 1 > out.png  # export entry 1 when it is an image
raffi clipboard copy 1            # copy an entry
raffi clipboard set "hello"       # add text to the clipboard
raffi clipboard set --mime image/png < shot.png
raffi clipboard status            # check the backend and history
```

The position of an entry changes as new items arrive. Scripts can use the IDs
shown by `list`; `delete` requires an ID. `--json` is available for `list`,
`show`, `set` and `status`.

```sh
raffi clipboard delete 3fa9c1d2e0
raffi clipboard clear -k image -y # delete all images
```

`clear` also deletes entries hidden by exclusion patterns. It requires
confirmation, or `-y` in scripts. See the [CLI reference](../../reference/cli-options/#clipboard)
for filters, output formats and backend limitations.

## Scripts and agents

For example, select an entry with [fzf](https://github.com/junegunn/fzf):

```sh
raffi clipboard list | fzf --delimiter '\t' --with-nth 4.. \
    --preview 'raffi clipboard show {1}' | cut -f1 | raffi clipboard copy -
```

Use `show --max-bytes 4000` to limit output, and `list --json` to get IDs for
scripts. `-` lets `copy` and `delete` read IDs from standard input. See the
[CLI reference](../../reference/cli-options/#clipboard) for JSON fields and
error codes.

## Raffi backend

Start the server to record clipboard history without CopyQ:

```sh
raffi --server
```

```yaml
addons:
  clipboard:
    backend: raffi
    max_items: 1000
    max_size_mb: 500
    max_image_size_mb: 50
```

The Raffi backend records text, images and file lists, along with copy times and
source apps on Hyprland, Sway and niri. Copying the same content again moves it
to the top. It skips password-manager copies unless you enable temporary
password entries. It does not import CopyQ history or record the primary
selection.

The history is stored in `~/.local/share/raffi/clipboard.db`, or under
`$XDG_DATA_HOME`. Restart the server after changing the backend, limits or
capture settings. If you use the supplied systemd service with a custom
`$XDG_DATA_HOME`, update its writable paths accordingly.

## Temporary entries

The Raffi backend can keep one-time codes and other matching text briefly:

```yaml
addons:
  clipboard:
    backend: raffi
    temporary_patterns:
      - '(?i)^verification code:'
      - '(?i)\bOTP\b'
    temporary_timeout: 60
    temporary_password_manager: true
```

Matching entries remain searchable and can be copied until they expire. The
browser shows a countdown. Copying the same content again resets the deadline;
selecting it in Raffi does not. Changing the timeout does not change existing
deadlines. Expiry removes the entry from the history, but does not clear the
clipboard.

Patterns use Rust regular expressions and are case-sensitive unless you add a
flag such as `(?i)`. `exclude_patterns` takes precedence over
`temporary_patterns`. These settings do not change what CopyQ records.

Deleting or expiring an entry removes it from history, but does not guarantee a
forensic erase from disk.

### Password managers

Password-manager copies are skipped by default. Set
`temporary_password_manager: true` to keep marked copies temporarily. They
still follow `temporary_timeout` and `exclude_patterns`.

## Copy times

Raffi's backend records copy times automatically. CopyQ needs its
[Show Copy Time](https://copyq.readthedocs.io/en/latest/command-examples.html#show-copy-time)
command: open CopyQ's command editor with F6 and add it. Older entries will not
have a copy time.

## Source app icons

Raffi's backend records the focused app on Hyprland, Sway and niri. For CopyQ
on Hyprland or Sway, open its command editor with F6 and paste the
<a href={`${import.meta.env.BASE_URL.replace(/\/$/, '')}/copyq/store-source-app.ini`}>source app command</a>.
Copies made in the background may show the app that was focused at the time.

## Privacy

Clipboard searches are saved in Raffi's search history and last-query cache.
Debug logs redact the search text. Previews are discarded when the window
closes.

To keep secrets off the command line and out of shell history, pass them on
standard input:

```sh
pass show site | raffi clipboard set --secret
pass show site | head -n1 | raffi clipboard set --secret --expire 30s
```

`--secret` marks the copy for clipboard managers. `--expire` records it
temporarily and clears the clipboard at the deadline if it still contains that
copy, even when `temporary_password_manager` is off. Exclusion patterns still
apply. These options require the Raffi backend.

## Configuration

Settings go under `addons.clipboard`. Restart the server after changing capture
settings.

| Setting | Default | Purpose |
| --- | --- | --- |
| `enabled` | automatic | Enable or disable the browser |
| `trigger` | `clip` | Keyword used to open it |
| `backend` | `auto` | Choose `auto`, `raffi` or `copyq` |
| `min_chars` | `3` | Hide shorter text entries; `0` shows all |
| `exclude_patterns` | `[]` | Hide matching text; the Raffi backend also skips recording it |
| `temporary_patterns` | `[]` | Keep matching text temporarily with the Raffi backend |
| `temporary_timeout` | `60` | Temporary entry lifetime in seconds |
| `temporary_password_manager` | `false` | Record password-manager copies temporarily |
| `max_items` | `1000` | Maximum entries in Raffi's history |
| `max_size_mb` | `500` | Total history size before older entries are removed |
| `max_image_size_mb` | `50` | Largest image Raffi records |
| `ocr.enabled` | `false` | Recognize text in images with Tesseract |
| `ocr.languages` | `[eng]` | Installed Tesseract language codes |
| `action` | `copy` | Enter action: `copy` or `hypr_paste` |
| `secondary_action` | `hypr_paste` | Ctrl+Enter action |
| `close_on_action` | follows `general.close_on_action` | Close after copying |

Exclusion patterns hide existing entries without deleting them. CopyQ continues
to record them; the Raffi backend skips new matches. Restart the server after
changing the patterns.

## Troubleshooting

- **No clipboard history server is running:** start `raffi --server` or
  CopyQ, then press **Ctrl+R**.
- **CopyQ is not installed or running:** install or start CopyQ, then refresh.
- **Raffi clipboard server is not running:** start `raffi --server`, then refresh.
  If its log reports missing data-control support, the compositor cannot provide
  clipboard history to Raffi.
- **Clipboard history kept changing:** press **Ctrl+R** to retry.
- **An image is not found by its text:** check `raffi clipboard show --json 1`
  for its OCR status. Install the configured Tesseract languages, then use
  the original application to copy the image again.
