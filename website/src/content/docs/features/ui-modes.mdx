## Fuzzel Mode

Fuzzel mode uses the external [Fuzzel](https://codeberg.org/dnkl/fuzzel) launcher. It is deprecated, but remains available for existing setups and Fuzzel-only builds.

### Features

- Lightweight and fast
- Seamless Wayland integration
- Uses system Fuzzel configuration
- Minimal resource usage

### Configuration

Fuzzel appearance is configured through `~/.config/fuzzel/fuzzel.ini`:

```ini fuzzel.ini
dpi-aware=yes
font=RobotoMonoNerdFont-Thin:size=16
terminal=kitty
width=50
layer=overlay
exit-on-keyboard-focus-loss=no
inner-pad=15
fields=filename,name

[colors]
background=282a36ff
text=f8f8f2ff
match=8be9fdff
selection-match=8be9fdff
selection=44475add
selection-text=f8f8f2ff
border=bd93f9ff
```

Refer to the [Fuzzel manual](https://man.archlinux.org/man/fuzzel.ini.5.en) for full configuration details.

### Usage

<Tabs>
<TabItem label="Command Line">

</TabItem>
<TabItem label="Config File">
```yaml
general:
  ui_type: fuzzel
```
</TabItem>
</Tabs>

### Building Fuzzel-Only Binary

For a significantly smaller binary (1.1 MB vs 15 MB), you can build without the native UI:

```bash
cargo build --release --no-default-features
```

This removes the iced GUI dependency while maintaining full Fuzzel functionality.

## Native Mode

Native mode uses Raffi's built-in iced-based graphical interface with fuzzy search, keyboard navigation, and theme support. It is the default and recommended interface in standard builds.

### Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl+J** / **Ctrl+K** | Scroll the right-hand preview pane down / up |
| **Ctrl+P** | Toggle the right-hand preview pane |
| **Ctrl+/** | Show separate keyword/action and keyboard-shortcut sections; typing filters them, and closing help restores the previous query |
| **Enter** | Launch the selected entry, or arm the selected keyword |
| **Tab** | Complete the selected keyword or file browser path |
| **Ctrl+Tab** / **Ctrl+Shift+Tab** | With `main_view` set, show one source at a time, then all of them again ([details](/configuration/general-settings/#main-view)) |
| **Alt+P** / **Alt+N** | Previous and next search history entry |
| **Ctrl+H** | Toggle hidden files in the file browser |
| **Backspace** | In the file browser, go up to the parent directory when the input ends with `/` |
| **Escape** | Close the keyword help, or quit |

## Automatic Selection

If no UI type is specified, Raffi selects:

1. **Native mode** in builds with the `wayland` feature (the standard build)
2. **Legacy Fuzzel mode** in Fuzzel-only builds, if `fuzzel` is available in `PATH`

<Aside type="note">
Fuzzel mode is deprecated and having Fuzzel installed does not change the default in a standard build. To use the legacy backend, select `-u fuzzel` or set `general.ui_type: fuzzel`.
</Aside>
