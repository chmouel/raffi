Raffi includes a currency converter with real-time exchange rates from the Frankfurter API.

## Overview

Convert between currencies by typing an amount with a trigger character (default `$`) followed by target currency codes. Exchange rates are cached for one hour to minimize API requests.

<Image src={currencyScreenshot} alt="Currency converter example" width={800} />

## Usage

### Basic Syntax

```text
<trigger><amount> to <currency>
<trigger><amount><source> to <target>
```

### Examples

<Tabs>
<TabItem label="Default Currency">

## Configuration

Configure the currency converter in your `raffi.yaml`:

```yaml raffi.yaml
addons:
  currency:
    enabled: true
    trigger: "$"
    default_currency: USD
    currencies:
      - USD
      - EUR
      - GBP
      - JPY
      - CAD
      - AUD
```

### Configuration Options

**`addons.currency.enabled`** `boolean` (default: `true`)

Enable or disable the currency converter.


**`addons.currency.trigger`** `string` (default: `$`)

Character that starts a conversion. Common options: `$`, `€`, `£`, `¥`.


**`addons.currency.default_currency`** `string` (default: `USD`)

Source currency when the query names none, so `$10 to eur` converts from USD. Use a 3-letter ISO code such as `EUR`, `GBP` or `JPY`.


**`addons.currency.currencies`** `array[string]` (default: `[USD, EUR, GBP]`)

Currencies to convert into when you type an amount with no target. With the
default source currency, `$100` lists 100 USD in every currency of this list
except USD, and `$100 gbp` does the same from GBP. A conversion with a target, such as `$10 to jpy`,
works for any supported currency whether or not it is in the list.


**`addons.currency.close_on_action`** `boolean` (default: `true`)

Close Raffi after Enter copies a result. Leave it unset to follow
`general.close_on_action`.

```yaml raffi.yaml
addons:
  currency:
    close_on_action: false
```

### Target Currencies

Choose which currencies an amount alone is converted into:

```yaml raffi.yaml
addons:
  currency:
    enabled: true
    currencies:
      - USD  # US Dollar
      - EUR  # Euro
      - GBP  # British Pound
      - JPY  # Japanese Yen
      - CAD  # Canadian Dollar
      - AUD  # Australian Dollar
      - CHF  # Swiss Franc
      - CNY  # Chinese Yuan
      - INR  # Indian Rupee
      - BRL  # Brazilian Real
```

<Aside type="tip">
Without a `currencies` list, an amount alone is converted into USD, EUR and GBP. Typing a target, as in `$10 to chf`, works for any supported currency either way.
</Aside>

## Exchange Rate API

Raffi uses the [Frankfurter API](https://www.frankfurter.app/) for exchange rates:

- Free and open-source
- No API key required
- Updated daily with European Central Bank rates
- Rates are cached for 1 hour locally

### Cache Behavior

<Steps>
1. **First Request**

   Fetches live rates from Frankfurter API

2. **Subsequent Requests**

   Uses cached rates (valid for 1 hour)

3. **After 1 Hour**

   Automatically fetches fresh rates on next conversion

</Steps>

## Conversion Patterns


  <details>
<summary>Implicit Source Currency</summary>

    When you don't specify a source currency, the `default_currency` is used:

    ```text
    $10 to eur      # 10 USD → EUR
    $50 to gbp      # 50 USD → GBP
    $100 to jpy     # 100 USD → JPY
    ```
  </details>

  <details>
<summary>Explicit Source Currency</summary>

    Specify both source and target currencies:

    ```text
    $10 usd to eur  # 10 USD → EUR
    $50 gbp to usd  # 50 GBP → USD
    $100 eur to jpy # 100 EUR → JPY
    ```
  </details>

  <details>
<summary>Compact Format</summary>

    No spaces between amount and currency:

    ```text
    $100eur to jpy  # 100 EUR → JPY
    $50gbp to usd   # 50 GBP → USD
    ```
  </details>


## Keyboard Shortcuts

Enter copies the converted amount. Escape closes Raffi.

## Disable Currency Converter

To disable the currency converter:

```yaml raffi.yaml
addons:
  currency:
    enabled: false
```

## Troubleshooting


  <details>
<summary>No conversion results</summary>

    1. Check internet connection
    2. Verify currency codes are correct (3-letter ISO codes)
    3. Ensure `enabled: true` in config
    4. Check that Frankfurter API is accessible
  </details>

  <details>
<summary>Wrong default currency</summary>

    Set `default_currency` in your config:

    ```yaml
    addons:
      currency:
        default_currency: EUR  # Change from USD to EUR
    ```
  </details>

  <details>
<summary>Trigger not working</summary>

    Make sure your trigger character doesn't conflict with other features:

    ```yaml
    addons:
      currency:
        trigger: "$"  # Or try "€", "£", etc.
    ```
  </details>
