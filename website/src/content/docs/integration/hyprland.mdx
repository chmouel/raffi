---
title: Hyprland Integration
description: Open Raffi with a key in Hyprland
---

Bind Raffi to a key in Hyprland and it opens on top of your current workspace.

## Configuration

Add the following to your Hyprland configuration file (typically `~/.config/hypr/hyprland.conf`):

```ini
$super = SUPER
bind = $super, R, exec, (val=$(raffi -pI); [ -n "$val" ] && hyprctl dispatch exec "$val")
```

If you use Hyprland's Lua configuration (`~/.config/hypr/hyprland.lua`), use
the equivalent Lua binding instead:

```lua
hl.bind("SUPER + R", hl.dsp.exec_cmd("(val=$(raffi -pI); [ -n \"$val\" ] && hyprctl dispatch exec \"$val\")"))
```

## How It Works

- `raffi -pI` runs Raffi in print-only mode with icons disabled for faster startup
- The selected command is stored in the `$val` variable
- `[ -n "$val" ]` checks that the output is non-empty (the user did not cancel)
- `hyprctl dispatch exec` launches the selected application through Hyprland's IPC
- The keybinding is `Super+R`

## Customization

### Using a Different Keybinding

You can bind Raffi to any key combination:

```ini
# Use Super+Space
bind = $super, Space, exec, (val=$(raffi -pI); [ -n "$val" ] && hyprctl dispatch exec "$val")

# Use Super+D (like dmenu/rofi)
bind = $super, D, exec, (val=$(raffi -pI); [ -n "$val" ] && hyprctl dispatch exec "$val")

# Use Alt+Space
bind = ALT, Space, exec, (val=$(raffi -pI); [ -n "$val" ] && hyprctl dispatch exec "$val")
```

### Enable Icons

If you prefer to use icons (slightly slower startup):

```ini
bind = $super, R, exec, (val=$(raffi -p); [ -n "$val" ] && hyprctl dispatch exec "$val")
```

### Use Custom Config

Specify a custom configuration file:

```ini
bind = $super, R, exec, (val=$(raffi -pI -c ~/.config/raffi/custom.yaml); [ -n "$val" ] && hyprctl dispatch exec "$val")
```

### Clipboard History

With the [clipboard browser](../../features/clipboard-history/) enabled, bind a key
that opens Raffi straight into it. Ctrl+Enter then pastes the chosen item into
the window you were using:

```ini
bind = $super, V, exec, raffi -i "clip "
```

### Transparency and Blur

Raffi is translucent by default (`opacity: 0.95`), and Hyprland blurs
what shows through as long as `decoration:blur:enabled` is on, which is the
default. Set `opacity` in `general`, or pass `--opacity`, to change it. See
[Transparency and Blur](../../features/themes/#transparency-and-blur).

## Testing

After adding the configuration:

1. Reload Hyprland: `hyprctl reload`
2. Press `Super+R` to launch Raffi
3. Select an application and press Enter to launch it

## Troubleshooting

### Raffi doesn't appear

- Verify Raffi is installed: `which raffi`
- Check Hyprland logs: `journalctl --user -xe`

### Applications launch multiple times or don't launch

- The `[ -n "$val" ]` check prevents execution when you close Raffi without picking anything
- Ensure you're using the full command including the conditional check
- Test manually: `val=$(raffi -pI); [ -n "$val" ] && hyprctl dispatch exec "$val"`
